# Fee Structure

> **The college has not published its own fees anywhere online.** Below are (A) a directory estimate and (B) the official fee caps for private nursing colleges set by the Haryana Government, which this college must follow. Use (B) as a guide, but get the actual fee sheet from the college.

## B. Official Haryana Govt fee structure for PRIVATE colleges
Source: *Haryana Govt. Gazette (Extra.), June 21, 2024*, **Annexure-VI**. The file is saved here as [Haryana_Gazette_2024_Nursing_Fee_Structure.pdf](Haryana_Gazette_2024_Nursing_Fee_Structure.pdf), from dmer.haryana.gov.in.

| Fee head | B.Sc & Post Basic B.Sc Nursing (annual) | M.Sc Nursing (annual) |
|---|---|---|
| Tuition fee incl. development charges | **₹60,000** (+5% annual increase) | ₹75,000 (+5% annual increase) |
| 15% NRI seats | USD 15,000 (entire course) | USD 15,000 (entire course) |
| Examination charges | Actual | Actual |
| University charges | Actual | Actual |
| Library fee | ₹3,000 | ₹3,000 |
| Sports & medical charges | ₹2,000 | ₹2,000 |
| Internet charges | ₹1,000 | ₹1,000 |
| Hostel fee | Not more than ₹60,000 or actual (whichever is less); no charge for fan & lighting | Same |
| Mess charges | Actual | Actual |
| Transport fee (if availed) | Actual | Actual |

**Rough annual total for B.Sc Nursing in the first year (2024-25 base):** ₹60,000 + ₹3,000 + ₹2,000 + ₹1,000 = **₹66,000**, plus exam and university charges at actuals. Hostel and mess are extra. With the 5% yearly increase, tuition works out to about ₹63,000 in 2025-26 and ₹66,150 in 2026-27.
